# 💼 HireHub

A full-stack MERN Job Portal application that connects Recruiters and Candidates. Recruiters can create companies, post jobs, and manage applications, while Candidates can search jobs, upload resumes, and apply for jobs.

## 🚀 Features

### Authentication
- Recruiter Registration & Login
- Candidate Registration & Login
- JWT Authentication
- Role-Based Authorization

### Recruiter Features
- Dashboard
- Create Company
- Manage Companies
- Post Jobs
- Edit Jobs
- Delete Jobs
- View Applicants

### Candidate Features
- Dashboard
- Search Jobs
- View Job Details
- Apply for Jobs
- Upload Resume
- View Applications
- Manage Profile

### General Features
- Responsive UI
- Protected Routes
- REST API
- Pagination
- Search & Filters
- Cloudinary Resume Upload
- MongoDB Atlas Database
